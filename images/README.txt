Coloca aquí tus fotos con estos nombres exactos (uno por página).
Si el archivo no existe, la página simplemente muestra un banner azul marino sólido — nada se rompe.

  bg-home.jpg          -> index.html (arriba del todo)
  bg-about.jpg         -> about.html
  bg-research.jpg      -> research.html
  bg-career.jpg        -> career.html
  bg-publications.jpg  -> publications.html
  bg-talks.jpg         -> talks.html
  bg-courses.jpg       -> courses.html
  bg-blog.jpg          -> blog.html
  bg-cv.jpg            -> cv.html
  bg-contact.jpg       -> contact.html

Recomendado: JPG, ancho mínimo 1600px, relación ancho:alto entre 3:1 y 4:1
(fotos panorámicas se ven mejor que verticales — piensa "portada de revista", no "foto de perfil").
El texto va en blanco sobre un degradado oscuro, así que evita fotos ya muy claras o muy ruidosas
en la mitad superior donde cae el título.
